# VPN — Windows 10/11 x64

## Версия 0.59: Discord в раздельном туннелировании

Исправлен выбор Discord через ярлык или устаревший путь: при подключении в правила добавляются существующие `app-<версия>\Discord.exe` из выбранной папки установки. Поддержаны также Discord PTB и Canary. Правила маршрутизации и Kill Switch используют одни и те же пути; другие установки Discord не затрагиваются. После обновления Discord во время VPN-сеанса переподключите VPN, чтобы перечитать пути. Сохранённый список приложений менять не нужно.

### Совместимость протоколов из 0.58

Добавлены **TUIC v5** и **AnyTLS** через встроенный sing-box и транспорт **HTTPUpgrade** через Xray. В ссылках gRPC теперь корректно переносятся `path` → serviceName и `host` → authority, включая VMess JSON-ссылки; режимы gun/multi не теряются. Конфликтующие параметры отвергаются. В Xray JSON поддержаны логический и именованный gRPC mode, HTTPUpgrade и псевдоним method. gRPC остаётся gRPC: клиент не подменяет его другим транспортом.

| Протокол / транспорт | URI / Base64 | Clash block YAML | Xray JSON | Ядро подключения |
|---|---|---|---|---|
| VLESS, VMess, Trojan | Да | Да | Да | sing-box / Xray по транспорту |
| Shadowsocks | Да, без плагинов | Базовые параметры | Да | sing-box; Xray для поддержанных цепочек |
| Hysteria2 / hy2 | Да; добавлен ALPN | Добавлены пароль, ALPN, salamander | Xray Hysteria v2 | sing-box |
| TUIC v5 | Добавлено | Добавлено | Нет | sing-box |
| AnyTLS | Добавлено | Добавлено | Нет | sing-box |
| HTTPUpgrade для VLESS/VMess/Trojan | Добавлено | Базовые http-upgrade-opts | Добавлено | Xray |
| gRPC для VLESS/VMess/Trojan | Исправлены распространённые варианты | grpc-opts | Да | Xray |

В YAML добавлены ALPN (inline-массив или блок списка), `ws-opts.headers.Host` и параметры новых протоколов. Импорт остаётся ограниченным: чужие маршруты, DNS, скрипты, провайдеры и YAML-конструкторы не исполняются. TUIC требует UUID и пароль; поддерживаются congestion_control cubic/new_reno/bbr и udp_relay_mode native/quic. TUIC и AnyTLS требуют TLS и собственного транспорта; проверка сертификатов не отключается. Произвольные дополнительные настройки могут быть отклонены: таблица не означает совместимость со всеми расширениями форматов.

Проверены фактические TCP-данные на локальных тестовых серверах для gRPC gun/multi и HTTPUpgrade, а также TUIC, AnyTLS и Hysteria2 с проверкой временного TLS-сертификата без изменения доверенных сертификатов Windows. Тесты используют только loopback, не меняют TUN и маршруты. Совместимость с произвольным внешним сервером, прохождение QUIC через сеть провайдера и UDP-передача отдельно не подтверждены. Отказ аутентификации личного REALITY остаётся отдельной нерешённой проблемой. OpenVPN, WireGuard, Hysteria v1, KCP и произвольные Shadowsocks-плагины в этом выпуске не добавлены.

Диагностическая утилита NetworkProbe теперь собирается без консольного окна, как штатный UI, чтобы её worker мог правильно создать консоль ядра при полном TUN-тесте. Сам TUN этим выпуском при разработке не запускался. Обновления приложения из файла планов остаются отложенными.

## Версия 0.57: просмотр и копирование ссылки

В редакторе профиля справа от ссылки добавлены глазик и кнопка копирования. По умолчанию ссылка скрыта; глазик показывает её до повторного нажатия или закрытия редактора. При новом открытии, переходе к удалению или локальному импорту ссылка снова скрывается. Копирование переносит фактическое содержимое поля в буфер обмена, даже когда оно скрыто, и не сохраняет изменения ссылки. Для пустого поля обе кнопки недоступны. Действия доступны с клавиатуры и имеют подписи для экранного диктора; ошибки буфера обмена не раскрывают ссылку. Текущее VPN-соединение эти действия не меняют.

## Версия 0.56: импорт из файла и текста

Откройте **Профили → + Добавить** (или карандаш у существующего профиля), затем **«Из файла…»** либо **«Вставить текст…»**. В окне импорта задайте имя, выберите локальный TXT/JSON/YAML/YML/CONF-файл или вставьте содержимое подписки. Нажмите **«Проверить»**: появится число распознанных, отклонённых и повторяющихся записей. **«Импортировать»** становится доступно только после проверки; изменение текста сбрасывает результат. При частичном распознавании импортируются только поддерживаемые серверы, о чём явно сообщает предварительный просмотр. Отмена ничего не меняет.

Поддерживаются обычный список URI, Base64, Xray/Happ JSON и ограниченный Clash block YAML из 0.55. Размер — до 4 МиБ файла и текста в UTF-8. Файлы читаются как строгий UTF-8, а при соответствующем BOM — UTF-16 LE/BE. Неправильная кодировка, сетевые пути и превышение размера отклоняются без вывода содержимого или пути в ошибку. HTTPS-ссылки в режиме локального импорта не загружаются; для них используйте обычное поле ссылки в редакторе.

Локальные серверы сохраняются в защищённых Windows настройках; исходный файл, путь и вставленный текст не сохраняются отдельно. У локального профиля нет сетевого обновления: переименуйте его обычной кнопкой «Сохранить» либо замените повторным импортом. Импорт активирует профиль и при действующем соединении отключает прежний VPN только после явного нажатия «Импортировать»; предупреждение видно в окне. Открытие окна, выбор файла, проверка и отмена соединение не меняют.

Сборка и проверки выполнялись в новой папке `dist-v0.56` на синтетических данных, без вмешательства в работающий VPN. Релиз 0.55 сохранён. Сетевое ядро и результаты реальных проверок из раздела 0.55 не изменялись; новая версия не заявляет устранение отказа REALITY на личном VPS.

## Версия 0.55: REALITY, gRPC, автоподбор и каскады

Windows x64, WinForms / C# 5 / .NET Framework 4.8. Официальный sing-box 1.14.4 продолжает обслуживать dual-stack TUN, DNS hijack и маршруты Windows. Встроенный Xray-core 26.10.31 теперь обслуживает VLESS REALITY/Vision, gRPC, XHTTP и поддерживаемые цепочки через защищённый локальный SOCKS-мост. Mihomo не используется. Проверяются конфигурации обоих ядер, включая окончательную конфигурацию TUN; процессы защищены Job Object. IP-адреса серверов исключены из маршрутов TUN, Xray направляется напрямую, основной DoH идёт через VPN.

Добавлен ограниченный импорт серверов Clash block YAML, в том числе REALITY с `support-x25519mlkem768`. Это поле совместимости Mihomo принимается при импорте; соединение выполняет Xray. Произвольные YAML-конструкторы, группы, правила и DNS подписки не выполняются. Для gRPC поддерживаются serviceName, authority, multiMode и логический Happ mode. Готовые каскады провайдера больше не теряются из-за этого поля. В JSON также поддерживаются цепочки `sockopt.dialerProxy` и `proxySettings` с `transportLayer=true`: до четырёх узлов, с отказом при цикле или отсутствующем теге. Входные узлы цепочки не выдаются за самостоятельный каскад. Автоподбор подписки сохраняется одной строкой; это сервер провайдера, а не новый локальный алгоритм выбора.

Проверено на предоставленных профилях: импорт 26 серверов провайдера, включая 3 каскада и один автоподбор, плюс личный VLESS REALITY/Vision. Обе закреплённые версии ядер приняли все 27 конфигураций. Реальные HTTPS-проверки через loopback-прокси личного сервера и трёх каскадов не прошли через действующее подключение; изолированный Xray сообщил отказ аутентификации REALITY (`received real certificate`). Успешная передача через личный VPN и внешний IPv4 194.26.192.151 **пока не подтверждены**. Новая ошибка REALITY сообщает о необходимости проверки профиля и времени Windows без раскрытия ключей.

По просьбе пользователя работающий VPN не отключался, активные настройки не перезаписывались, VPS не изменялся. Полный TUN-тест, DNS через него и восстановление маршрутов/DNS после отключения или аварии требуют отдельного запуска после завершения текущего соединения. При выключенном Kill switch ОС удаляет временные маршруты вместе с TUN; при включённом Kill switch аварийная блокировка намеренно сохраняется до явного отключения / «Восстановить интернет». Автоматическое восстановление доступа при аварии с включённым Kill switch этим выпуском не заявляется.

Локально подготовлены два профиля в DPAPI-файле `cache/prepared-profiles.private.dat`; он не включён в ZIP или установщик. Когда можно будет завершить текущий VPN, закройте старый клиент через «Выход» в трее и выполните из Windows PowerShell 5.1:

```powershell
./tools/import-prepared-profiles.ps1
./dist-v0.59/doomraVPN.exe
```

Импорт проверяет блокировку запущенного интерфейса, сохраняет зашифрованную резервную копию `settings.dat`, обновляет профили и выбирает Personal VPS. HWID не меняется; для подготовки подписки провайдера он передавался только после явного разрешения. Подготовленный пакет доступен только текущей учётной записи Windows. Для повторной диагностики: `build.ps1 -Test -BuildProbe`, затем `dist-v0.59/NetworkProbe.exe --check-profile cache/subscription-1.private.dat` (только локальный прокси) или `--i-accept-network-change` с тем же файлом (настоящий TUN, запускать только когда допустим разрыв текущего VPN). Отчёт `network-probe-safe.txt` не содержит ключей и ссылок; фактический IP сравнивается с ожидаемым.

В настройках можно направлять трафик через VPN по списку приложений или сайтов. В режиме «Сайты» можно указать домен или вставить ссылку. Правило действует на весь домен и его поддомены. При обрыве в режиме по сайтам Kill switch блокирует прямой доступ для всех приложений. Kill switch блокирует защищаемый трафик при обрыве VPN, а ручное отключение возвращает обычный доступ к интернету. Импорт поддерживает Hysteria2 и VLESS XHTTP. Для XHTTP в архив включён Xray.

В версии 0.18 фоновые флаги ярче в обеих темах: непрозрачность 34% в тёмной и 28% в светлой. Вращение металлического логотипа ускорено с 3 до 0,8 секунды; во время движения интервал таймера 16 мс, перерисовывается только карточка соединения (кроме общего обновления статистики). Это целевой интервал, а не гарантия 60 кадров/с; GIF не используется. Выровнены нижние информационные блоки и разделители, убрано затемнение списка при открытии профилей. Светлая тема использует более тёмную серую палитру с контрастными границами. Обновление серверов перенесено на главную панель рядом с настройками (круговая стрелка), из редактора убрано. Проверка доступности обозначена значком пульса. Добавлены независимые профили подписок: создание, переключение, переименование и обновление серверов. Предыдущая подписка переносится в «Основной» с сохранением HWID. Список серверов и выбор запоминаются отдельно для каждого профиля. Данные сохраняются через Windows DPAPI в прежнем settings.dat.

Металлический логотип и JetBrains Mono сохранены. Кнопка подключения без постоянной обводки, с жирным текстом 16px и клавиатурным подчёркиванием. Проверка всех серверов обозначена значком пульса, при проверке — значком остановки; пояснение и прогресс видны при наведении. Текст рисуется нативным GDI в физических пикселях, метаданные не меньше 13px. Проверены обычный размер, минимальное окно и синтетический масштаб 150%; автоматическое переключение DPI между мониторами пока не реализовано.

Настройки (шестерёнка) открываются отдельной страницей внутри окна, с кнопкой «Назад» и возвратом по Escape. Там находится переключатель светлой темы; выбор сохраняется. Флаги показываются рядом с названиями серверов. Карточки имеют нейтральный фон. Малые флаги не растягиваются: пропорции сохраняются. Встроены PNG 250px для значков и 1000px для фона, без загрузки во время работы. Для США, Нидерландов, Германии, Швеции и Финляндии фон заменён присланными вертикальными SVG 840×960; исходники сохранены в assets/custom-flags, PNG формируются при сборке. Поле ссылки скрывается небольшими средними точками. Кнопка «Профили» открывает управление подписками.

Размер по умолчанию — 1040×720, минимальный — 900×640, включая верхнюю панель. Поддерживаются изменение размера, сворачивание, разворачивание, Tab, стрелки/Home/End, колесо мыши и полоса прокрутки. При перетягивании границы интерфейс перестраивается сразу. Текст, эмблема и кнопки сохраняют пропорции. Зелёный индикатор появляется после успешной проверки связи через VPN.

Встроены флаги стран, включая США, Канаду и Великобританию. Страна определяется по названию, коду или флагу в метаданных подписки, затем по имени хоста. Это не GeoIP-проверка физического местоположения; при неизвестной стране отображается глобус. Шрифты и флаги работают без установки и загрузки из интернета.

## Установка и работа в фоне

Запустите `doomraVPN-0.59-setup-windows-x64.exe` и подтвердите повышение прав. Установщик добавляет VPN в Program Files, меню «Пуск» и список установленных приложений. Требуется .NET Framework 4.8. Служба Windows запускается автоматически и принимает команды только от учётной записи, для которой установлен клиент. При установке с рабочего стола это пользователь текущего сеанса Windows. Обновление сохраняет эту привязку. Подключение из установленного интерфейса выполняется через службу без повторного повышения прав. Portable-архив сохраняет подключение через UAC.

Крестик окна сворачивает приложение в трей. В меню трея можно открыть окно, подключить или отключить VPN и выбрать «Выход» для завершения соединения и программы. В настройках установленной версии есть два независимых переключателя. Первый запускает приложение при входе в Windows. Второй подключает выбранный сервер при таком запуске. Оба выключены по умолчанию.

При удалении установщик останавливает службу и снимает её правила блокировки. Профили подписок и ID установки хранятся в прежней папке пользователя и сохраняются. Перед обновлением или удалением закройте клиент через «Выход» в трее.

## Запуск

1. Закройте предыдущую версию клиента. Распакуйте `doomraVPN-0.59-windows-x64.zip` целиком и запустите `doomraVPN.exe`. Требуется .NET Framework 4.8.
2. Откройте «Профили». Нажмите «+ Добавить», введите название и HTTPS-ссылку, затем «Сохранить». Для переименования нажмите карандаш возле профиля. Сохранение неизменённой ссылки меняет только название, без запроса к провайдеру. Круговая стрелка рядом с настройками на главной панели загружает серверы текущего профиля заново и отключает активный VPN. При отсутствии профиля и во время другой операции она недоступна. Enter сохраняет, Escape или щелчок снаружи закрывает меню. Корзина в редакторе удаляет профиль после подтверждения. Отмена возвращает введённое имя и ссылку. Удаление активного профиля отключает VPN и выбирает соседний; удаление последнего оставляет пустой список. Удаление не меняет HWID и не отправляет запрос провайдеру. Максимум 24 профиля и 10 000 серверов суммарно. Переключение профиля отключает текущий VPN; открытие редактора и простое переименование его не отключают.
3. Выберите сервер в списке. Если VPN уже подключён, нажатие на другой сервер переключает соединение без повторного запуска служебного процесса. Список серверов представлен таблицей с отдельными столбцами для протокола, статуса и времени проверки. Список можно прокручивать во время подключения и переключения. Правила маршрутизации и Kill switch можно изменить при включённом VPN. Они вступят в силу после отключения и нового подключения.
4. Значок пульса возле «Профили» проверяет до трёх серверов одновременно без TUN и прав администратора. «Доступен» означает, что через его VPN-протокол удалось выполнить HTTPS-запрос с проверкой сертификата. «Нет ответа» означает неудачу проверки с этой машины сейчас, а не доказанную неисправность сервера во всём мире. Повторное нажатие останавливает очередь. Рядом с результатом отображается местное время завершения проверки. Результат сохраняется в профиле, включая успешное подключение через VPN. Сетевой запрос проверки ограничен 6 секундами, а запуск вместе с проверкой — 12 секундами и использует Cloudflare / резервный Google. При недоступности обоих контрольных адресов успешный результат невозможен.
5. «Подключить» запускает полный TUN. В portable-версии подтвердите запрос UAC. После успешной проверки кнопка меняется на «Отключить». Во время запуска можно отменить подключение.
6. Крестик сворачивает клиент в трей. Для отключения и завершения используйте «Выход» в трее.

HWID и автопереподключение постоянно включены по запросу пользователя. При обновлении подписки передаётся сохранённый случайный ID установки и тип ОС; это может занять слот устройства у провайдера. ID не меняется при обновлении версии и хранится через Windows DPAPI. Чтобы сохранить существующую подписку и идентификатор, используется прежняя папка `%LOCALAPPDATA%\LunaVPN`. Переименование приложения не создаёт новое устройство.

Для совместимости с провайдером запросы подписки используют User-Agent Happ и сохранённый идентификатор установки. Поддерживаются URI/Base64 и извлечение поддерживаемых серверов из Xray/Happ JSON. Импортируются VLESS/Reality, VMess, Trojan и Shadowsocks с поддерживаемыми TCP/WebSocket/gRPC. VLESS XHTTP и Hysteria2 поддерживаются. Включённый Xray mux и непереносимые параметры остаются неподдерживаемыми; ограничения YAML и цепочек описаны в разделе 0.55. Чужие DNS, маршруты, скрипты и входящие соединения из подписки не исполняются.

## Статистика

Срок и расход подписки берутся из HTTP-заголовка subscription-userinfo (upload, download, total, expire) при успешном обновлении подписки, без дополнительных запросов. Это снимок данных провайдера на момент обновления, включая расход других устройств, если провайдер так считает. Нулевой total означает безлимит, нулевой expire — бессрочно; неизвестные значения отображаются как «Нет данных». Для появления данных существующей подписки обновите её через панель подписки.

Время соединения считается только при подтверждённом подключении и приостанавливается на восстановлении связи. Текущая скорость приёма и отправки в МБ/с отображается под статусом «Подключено». Принятые и отправленные байты измеряются раз в секунду по собственному адаптеру LunaVPN-TUN с проверкой его адреса. Отсчёт начинается после подтверждения соединения; физические адаптеры не учитываются. При отсутствии счётчика отображается «—». Трафик — объём IP-пакетов TUN, а не точный биллинг провайдера. Последний результат остаётся после отключения и сбрасывается при новом подключении. ГБ/МБ — десятичные единицы.

## Проверка и сеть

Кнопка проверки создаёт отдельный процесс официального sing-box с локальным прокси на 127.0.0.1 и временным паролем и выполняет HTTPS только через этот прокси. Она не включает TUN, не меняет системный прокси, DNS или маршруты Windows. Дочерний процесс защищён Windows Job Object и завершается по окончании проверки, отмене или закрытии приложения. Результат проверки не включает VPN автоматически.

Полное подключение использует dual-stack TUN, перехват DNS и strict_route. Bootstrap DoH для имени VPN-сервера идёт напрямую, основной DoH — через сервер. Kill switch включается отдельно. При аварии его правила могут оставаться активными до ручного отключения или команды «Восстановить интернет». Другие VPN приложение не отключает.

В 0.6 исправлен bootstrap DNS: sing-box 1.14.4 не принимал detour к пустому direct outbound. Реальный TUN после исправления не проверялся. Новая проверка доступности проверена на синтетическом недоступном loopback-сервере; реальная подписка в ходе изменений интерфейса не запрашивалась и TUN не запускался.

## Исходники и сборка

```powershell
./tools/fetch-core.ps1
./tools/fetch-xray.ps1
./tools/build.ps1 -Test
./tools/package.ps1
```

Результат: `dist-v0.59\doomraVPN.exe`; ZIP: `releases\doomraVPN-0.59-windows-x64.zip`. Сборка системным C# 5 csc, без SDK и NuGet. Для отдельной папки: `build.ps1 -Test -OutputDirectory dist-v0.59`, предварительно скопировав в неё проверенные sing-box.exe и xray.exe; затем `package.ps1 -InputDirectory dist-v0.59`.

Установщик собирается командой `./tools/build-installer.ps1 -InputDirectory dist-v0.59 -Compiler "C:/path/to/ISCC.exe"`. Для подписанного выпуска подпишите `doomraVPN.exe` сертификатом издателя и передайте установщику команду подписи через `-SigningCommand` (с заполнителем Inno Setup `$f` для файла). Без сертификата установщик и приложение выпускаются без подписи.

Автоматические проверки включают совпадение частичной и полной отрисовки анимации, доступность обновления профиля на главной панели, импорт/отказы JSON и URI, DPAPI/HWID, категории ошибок, DNS runtime без TUN, конфигурация loopback-проверки, недоступный loopback-сервер, очистка процессов, Job Object и правило зелёного индикатора. Отрисовка проверена на демонстрационных данных в основном размере, минимальном размере, обеих темах, с меню профилей/редактором и при масштабе 150%.
