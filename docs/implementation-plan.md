# План VPN-клиента

Цель: личный Windows 10/11 x64 клиент с русским интерфейсом, HTTPS-подписками и TUN sing-box.

Стек: C# 5 / .NET Framework 4.8 / Windows Forms, доступный системный csc; без NuGet.
Ядро: sing-box 1.14.4, GPL-3.0-or-later с дополнительным ограничением имени upstream.
Оболочка: GPL-3.0-or-later. Имя Luna VPN не подразумевает связь с SagerNet.

Архитектура:
- src/Subscriptions.cs: строгий импорт URI, Base64, allowlist параметров, HTTPS загрузка до 4 MiB / 20 секунд.
- src/Configuration.cs: только собственная конфигурация sing-box, dual-stack TUN, DoH через VPN, bootstrap только адреса сервера.
- src/Storage.cs: DPAPI CurrentUser, ACL, атомарная запись, диагностический журнал без содержимого ядра.
- src/Worker.cs: отдельный elevated процесс, IPC с ACL текущего пользователя, ядро с проверкой хеша, graceful stop и Job Object.
- src/MainForm.cs: тёмный UI, поиск, TCP latency, трей, безопасные статусы, переподключение.
- tests/Tests.cs: реальные fixtures и отрицательные случаи, DPAPI roundtrip, core check (без run/TUN).
- tools/build.ps1 и tools/fetch-core.ps1: воспроизводимая сборка и официальный архив с SHA-256.

Этапы (выполняются без дополнительных согласований по исходному запросу):
1. [x] Тесты импорта, RED -> реализация -> GREEN; неизвестные/небезопасные параметры отклоняются, исходный URI не включается в ошибку.
2. [x] Конфигурации четырёх протоколов, проверка sing-box check без подключения.
3. [x] DPAPI, worker lifecycle, отсутствие открытых файлов конфигурации, проверки отсутствующего/изменённого ядра.
4. [x] UI, трей, загрузка и TCP-проверки, сборка и запуск окна без TUN. Визуальная проверка ограничена тайм-аутом доступа computer-use.
5. [x] Проверка кода, инструкция и пакет с исходниками/лицензиями.

Ограничение проверки: не запускать TUN и не менять активную сеть без отдельного согласия пользователя.
При аварии UI worker получает EOF, завершает ядро; Job Object страхует смерть worker.
Не менять настройки чужих адаптеров/прокси. Не обещать kill switch: после остановки ядра обычная сеть доступна.
Проверить отдельно: пустые/смешанные подписки; неизвестный transport; отмена UAC; обрыв IPC; выбор другого сервера во время подключения.

29 проверок: импорт/отказы, конфигурации, DPAPI/повреждение файла, хеш ядра, IPC, Job Object, CTRL_BREAK реального ядра без inbounds/сетевых запросов.
Исправлены замечания независимого code review: ожидание завершения worker, отсутствие имён неизвестных параметров в диагностике, ACL IPC для UAC с другой учётной записью администратора.
Ruling: конфигурация через stdin вместо временного открытого файла — не нужен журнал секретных файлов для аварийной очистки.
Ruling: до 3 повторных запусков ядра за сеанс внутри elevated worker; UAC не повторяется на каждом восстановлении.
Ruling: если helper не завершился за 25 с, показать ошибку остановки и продолжить ждать; не объявлять отключение и не запускать новый TUN до реального выхода helper.
Внешний релиз не публиковался. Настоящая подписка и сетевые проверки требуют участия пользователя; приложение само при запуске VPN не включает.

## Исправление HWID (0.4)

Локально проверены только безопасные метаданные сохранённых настроек: выбран Happ, импортирована служебная инструкция с написанием «рекомендованое». Прямой запрос без HWID к сохранённому адресу подтвердил HTTP 200, x-hwid-not-supported=true, x-hwid-max-devices-reached=false. Секретные данные и тело ответа не выводились, устройство не регистрировалось.
Добавлен opt-in HWID: случайный ID сохраняется через DPAPI перед отправкой, стабилен между запусками, не меняется для обхода лимитов. При отказе сохранения ID не отправляется. Cross-origin редиректы с HWID блокируются. Сырые параметры подписки не исполняются.
41 безопасная проверка прошла; независимый review не нашёл блокирующих замечаний. Работа с новым HWID у реального провайдера остаётся непроверенной до действия пользователя в интерфейсе. Новый пакет — releases/LunaVPN-0.4-windows-x64.zip.

## Исправление JSON (0.5)

Пользователь сам включил HWID и получил ошибку «Строка слишком длинная». Автоматическая проверка отклонила диагностический запрос с ID; после отдельного явного разрешения пользователя выполнен ровно один запрос с существующим ID. Он подтвердил JSON около 52 КБ с VLESS/Trojan, TCP/WS/gRPC/XHTTP, TLS/Reality; тело не сохранялось и не выводилось. Разрешение на дополнительные запросы не предполагается.
Добавлен src/XrayImport.cs: извлекает валидированные модели серверов без исполнения DNS, routing, inbounds, selector и других глобальных полей. Поддерживает массив конфигураций и плоский/старый синтаксис настроек. XHTTP и непереносимые активные функции отклоняются. Ошибки структур отдельных конфигураций не сбрасывают другие серверы; конфликтующие Host-заголовки отклоняются.
48 тестов прошли, включая большой minified JSON, Base64 JSON, Reality core check, отказы TLS bypass/proxy chain, частичные ошибки. Замечания независимого review исправлены. Реальный импорт новой версией и подключение не проверялись; пакет releases/LunaVPN-0.5-windows-x64.zip.

## Исправление старта DNS и имён (0.6)

Пользователь сообщил 11 импортированных серверов с именами proxy и ошибку ядра. Все 11 сохранённых конфигураций прошли check, но это не доказывает запуск DNS/TUN. После отдельного явного разрешения выполнен ровно один короткий TUN-тест производственного worker через NetworkProbe: ERROR_DNS, выход 1, helper завершился.
На синтетическом loopback-примере без inbounds воспроизведено точное сообщение: start dns/https[bootstrap]: detour to an empty direct outbound makes no sense. Удалён detour direct у bootstrap DNS. Новый регрессионный тест реально запускает DNS на конфигурации без TUN и внешних адресов, затем штатно завершает ядро. До фикса падал, после проходит. Всего 54 теста прошли; 11 сохранённых конфигураций проходят check. Дополнительный реальный TUN-тест не выполнялся и не подразумевается разрешённым.
Названия JSON: remarks имеют приоритет над proxy-тегом. Для старых записей добавлены честные hostname-подсказки с явной пометкой, без стороннего GeoIP. TCP-индикатор остаётся временем открытия сокета с уточнением его ограничений. Логи ядра классифицируются в памяти в статические категории и код выхода, сырые строки не сохраняются.

## Минимальный интерфейс doomra VPN (0.7)

По прямому запросу пользователя оставлены подключение, выбранный сервер, список, добавление подписки и проверка выбранного сервера. Поиск, вкладки, TCP-цифры, поля/селектор подписки в главном окне, галочки и отдельный трей удалены. Подписка вводится в модальном окне. HWID и автопереподключение включены без переключателей по явному указанию пользователя. Папка DPAPI и существующий ID сохранены, новое устройство не создаётся при переименовании. Имя окна/программы/пакета — doomra VPN / doomraVPN.exe.
Новая проверка использует отдельный sing-box mixed proxy на loopback и HTTPS 204 с проверкой сертификата строго через него. Нет TUN, системного proxy или изменений DNS/маршрутов. Тайм-аут 20 с, отмена при закрытии, дочерний Job Object. Отрицательный ответ подписан «Нет ответа», успешный «Доступен», состояние не сохраняется между запусками. Нет автоматических запросов к подписке или серверам при открытии программы.
57 тестов прошли; новые проверки: отсутствие TUN в probe-конфигурации, отказ закрытого loopback VPN endpoint, завершение процесса при закрытии probe Job Object. Реальные запросы и TUN в ходе 0.7 не запускались.

## Стеклянный дизайн и индикатор (0.8)

Реализован утверждённый визуальный концепт: ресурсы background.jpg и connect.jpg взяты из предоставленных изображений и встроены в EXE; фон кэшируется, размыт и переведён в нейтральный металл. Стеклянные панели, пилюли и строки рисуются GDI+, круглая кнопка использует орнамент и символ питания. Нет крупного названия/логотипа в основной области. Символ — значок EXE/ярлыка, файл doomra.ico входит в пакет.
Собственная верхняя панель: название, красный/зелёный индикатор, стандартные действия окна. UiState.IsOnline допускает зелёный только для CONNECTED, существующей сессии, без отмены/закрытия. Ручное отключение сразу переводит состояние в STOPPING и красный. Восстановление/ошибки/отсутствие сессии также красные.
58 тестов прошли. Реальная отрисовка формы экспортирована без показа окна на синтетических данных в размерах 960×712, 780×580 и с прокруткой. Никаких HTTP-запросов/реальных настроек для preview не использовано. Исправлено замечание независимого review о рассинхронизации GDI-текста при прокрутке: весь список теперь рисуется в явных viewport-координатах; колесо, клавиатура и drag thumb используют один offset. Реальный TUN не проверялся.

## 0.12 — полировка по аудиту Unslop

Сохранены металлический PNG, JetBrains Mono, жирные кнопки, трёхсекундный оборот и семантический индикатор. Поля: шаг24, строка60/шаг64; рисование, прокрутка, hit testing и accessibility используют общую геометрию. Кнопка проверки всех серверов перенесена в заголовок списка. Провайдерская подписка под выбранным сервером, статистика сеанса под списком. Минимальный текст12px, значения14–16px, обычный регистр, единая русская десятичная запись. Удалены фоновые засветки и рамки каждой строки. Локализуются известные страны в отображаемом названии; исходное имя не изменяется и доступно в подсказке. Короткие коды стран в названиях распознаются только в верхнем регистре, чтобы No limits/At home не становились странами. Меню подписки подписано как ввод ссылки, без обещания произвольного ключа. 74 теста прошли; изображения проверены в 1040×720, 900×640 и с меню. Живая подписка и TUN не использованы.

## 0.13 — профили, темы и текст

Модель SubscriptionProfile и ProfileStore: перенос legacy подписки, общий неизменяемый HWID, независимые ссылки/метаданные/серверы/выбор. DPAPI сохраняет коллекцию и тему; ограничены число профилей, число серверов и размер зашифрованного файла. Меню canvas: список/переключение/карандаш/создание, редактор имени и маскированной HTTPS-ссылки, явное обновление. Переименование не делает запрос. Переключение/обновление отключает VPN, открытие редактора нет. Busy-gating и accessibility остаются согласованными. Настройки содержат только переключатель светлой темы. Кнопка подключения без постоянной обводки, жирный текст16px; проверка — refresh/stop icon. Флаги250px для значков сохраняют аспект,1000px для фона загружаются лениво. Нативный GDI текст в физических координатах; TextCanvas явно переносит clip в device-space и восстанавливает DC/Graphics. Пиксельный тест ловит обрезание на1.5x и выход за clip. 83 теста прошли; синтетические превью обеих тем и меню. Подписка пользователя и TUN не использованы.


## 0.14 — удаление профилей и страница настроек

Добавлены Remove и ProfilesInitialized: последний удалённый профиль очищает legacy URL/metadata/servers/selection и не восстанавливается при загрузке. Активный профиль отключается перед удалением, неактивный не прерывает соединение; HWID неизменен. Корзина редактора открывает inline подтверждение, отмена сохраняет черновик. Настройки — отдельная страница под общей верхней панелью, Back/Escape и светлая тема; серверные действия недоступны через pointer/keyboard/accessibility. Пользовательская подписка и реальный TUN не использованы.
